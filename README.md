# BlinkIT Grocery Sales Analysis

## Project Overview
This project analyzes grocery sales data to understand product performance, outlet performance, and business improvement opportunities.

## Objectives
- Identify top-performing product categories.
- Compare sales across outlet types and locations.
- Explore relationships between product characteristics and sales.
- Recommend practical strategies to improve business performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Files
- `BlinkIT_Analysis.ipynb` — analysis code and visualizations.
